# ☕ BrewHaven — Artisan Coffee Website

A modern, responsive coffee shop website focused on clean UI, smooth interactions, and real-world frontend structure.

---

## ⚙️ What It Does

- Displays a modern coffee shop landing page
- Interactive menu with category tabs (Hot, Cold, Food)
- Dynamic testimonials slider
- Image gallery with lightbox preview
- Contact form with UI feedback
- Fully responsive across devices

---

## ⭐ Features

- ✅ Clean and modern UI/UX design  
- ✅ Interactive menu system (JavaScript)  
- ✅ Testimonials carousel/slider  
- ✅ Image lightbox gallery  
- ✅ Smooth scroll & animations  
- ✅ Mobile responsive layout  

---

## 🛠 Tech Stack

- HTML 
- CSS
- JavaScript
